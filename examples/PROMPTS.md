# Примеры вопросов к MCP Реестра реестров

Вопросы, которые можно задать ассистенту (Claude, ChatGPT, Cursor и др.) после подключения `https://reestr-reestrov.ru/api/mcp`.
Для каждого указано, какой инструмент он вызовет, и фрагмент реального ответа (17.11.2026). Ключ не нужен: без ключа до 10 строк в ответе и 30 запросов в сутки.

## 1. Проверка контрагента по ИНН

> Проверь ИНН 7707083893: какие у компании лицензии и допуски, что действует, что прекращено?

`check_permits {"inn": "7707083893"}` -> найден в 26 источниках из 99, например:

| Источник | Статус | Номер |
|---|---|---|
| rtn-license-opo (лицензия Ростехнадзора, опасные объекты) | active | Л057-00109-77/00536964 |
| rtn-lift (реестр лифтов) | active | 709265 |
| rkn-svyaz (лицензия на услуги связи) | terminated | 40238 |
| fsrar-license (лицензия на алкоголь) | terminated | 50РПО0002118 |

У каждого источника в ответе есть `updated_at` (дата копии) и `source_url` (первоисточник).

## 2. Член СРО по номеру

> Найди в реестре НОСТРОЙ члена СРО с номером 0689. Он действующий?

`query_registry {"source": "nostroy", "number": "0689"}`:

```json
{"status": "terminated", "number": "0689", "date_from": "2014-08-21",
 "name": "ООО \"Объединение Транс-Континенталь\"",
 "extra": {"status_text": "Исключен", "sro_number": "СРО-С-130-21122009", "region": "Республика Крым"},
 "url": "https://reestr.nostroy.ru/member/3810511"}
```

## 3. Поиск по названию в одном реестре

> Есть ли в реестре МФО Банка России компании со словом "Займ" в названии? Покажи 3 действующие.

`query_registry {"source": "cbr-mfo", "name": "Займ", "status": "active", "limit": 3}` -> например, ООО МКК "Микрозайм", рег. номер 2110323000091, Краснодар, действует с 08.07.2011.

## 4. Какие источники есть

> Какие реестры лицензий можно проверить через этот сервер?

`list_sources {"query": "лицензия"}` -> 33 источника (Ростехнадзор, Росалкогольтабакконтроль, Роскомнадзор, МЧС, Росздравнадзор, Рособрнадзор и др.).

> Что есть по таможне?

`list_sources {"query": "ФТС"}` -> fts-broker, fts-svh, fts-carrier, fts-sklad, fts-dutyfree, fts-ueo.

## 5. Справка о реестрах (каталог 596 реестров)

> Где посмотреть сведения о банкротстве компании и есть ли у реестра API?

`search_registries {"query": "банкротство"}` -> ЕФРСБ (Федресурс), Минэкономразвития, открытый, есть API, поиск по ИНН, ссылка на проверку.

> Я открываю клинику (ОКВЭД 86.21). В какие реестры мне нужно попасть?

`registries_for_okved {"okved": "86.21"}` -> 7 реестров, включая реестр операторов персональных данных Роскомнадзора (нужен любому бизнесу).

> Расскажи подробно про ЕГРЮЛ: кто ведёт, по какому закону, как получить выписку.

`get_registry {"id": "egrul"}`

## 6. Промышленная продукция (нацрежим в закупках)

> Есть ли у производителя с ИНН ... продукция в реестре российской промышленной продукции (ПП 719)?

`query_registry {"source": "gisp-pp719", "inn": "..."}` -> число действующих и исключённых позиций, коды ОКПД2, последнее заключение.

## Советы

- Сначала `list_sources`, потом `query_registry` с найденным `id`.
- Поиск по названию работает внутри одного источника; по ИНН во всех сразу: `check_permits`.
- `found: false` у источника с полем `error` не значит "нет в реестре": источник был недоступен.
- Ссылайтесь на `source_url` и `updated_at`: это копия официальных открытых данных, а не сам реестр.

# Example prompts (English)

- "Check Russian company INN 7707083893: which licenses and permits are active?" -> `check_permits`
- "Is SRO member number 0689 in the NOSTROY registry still active?" -> `query_registry` (source `nostroy`)
- "Which license registries can you query?" -> `list_sources {"query": "лицензия"}`
- "Which registries does a clinic (OKVED 86.21) need to be in?" -> `registries_for_okved`

Answers are in Russian (source data is Russian); the assistant can translate them.
